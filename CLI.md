# CLI Commands (skeleton)

- `exit` — завершает работу CLI.
- `quit` — завершает работу CLI.

## JSON команды

- Ввод начинается с `{` и корректно парсится как JSON → CLI считает это структурированной командой и передаёт dict в `core.engine.handle_command`.
- Ответ ядра (dict) печатается в виде JSON.
- Некорректный JSON и обычный текст не интерпретируются и выводятся как есть (echo).
