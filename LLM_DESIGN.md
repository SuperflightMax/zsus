# LLM Design

## Роль LLM

LLM используется как интерпретатор человеческого ввода.

LLM:
- понимает намерение пользователя
- формирует DraftCommand
- генерирует человеко-понятный ответ

LLM не:
- выполняет действия
- вызывает core engine
- изменяет состояние системы напрямую

## DraftCommand и ExecutableCommand

LLM формирует DraftCommand — промежуточное описание намерения.

Система:
- оценивает уверенность
- применяет правила и дефолты
- формирует ExecutableCommand
- либо отклоняет запрос

## Языковая политика

Ввод пользователя может быть на любом языке.
Ответы пользователю всегда формируются на украинском языке.
